## Preserved design and substitutions

Public images use selected original HTML sections and CSS without application scripts. Administrative images reconstruct selected visible JSX layouts as inert HTML using original admin CSS. Palette, spacing, RTL direction and major layout relationships follow the source. Outer frames and English captions are portfolio additions. Minor form-density and framing adjustments were made for the concepts. Nonessential admin fields/interactions are omitted to fit the composition.

Original photography and image logos are excluded. The unbranded bottle is an original code-drawn illustration, not real packaging or a product photograph. External fonts were replaced by system Arial/Georgia/serif fallbacks, so typography is approximate. No font files are included. Motion is disabled.

Product-section copy and ingredient labels are illustrative and make no product-composition claim. Dashboard values are dashes rather than fabricated metrics or operational results. Offer prices and dates are omitted; the draft is unsaved. No customer names, reviews, contacts, credentials, remote image URLs or database records were used. No backend operations occurred.
